An intelligent, lightning-fast financial advisor web application built with **Python**, **Streamlit**, and powered by **Llama 3.3 (70B)** via the **Groq API**. This tool analyzes your monthly budget, calculates your financial surplus/deficit, and provides actionable, personalized financial advice.

---

## ✨ Features
* **Interactive Dashboard:** Clean and intuitive UI built with Streamlit.
* **Instant Analysis:** Powered by Groq's LPUs, delivering AI responses in milliseconds.
* **Smart Budgeting:** Automatically calculates total expenses, remaining balance, and expense-to-income ratios.
* **Personalized Advice:** Offers tailored savings plans, expense reduction tips, and goal-tracking timelines.

## 🛠️ Tech Stack
* **Frontend:** [Streamlit](https://streamlit.io/)
* **Backend Framework:** [LangChain](https://python.langchain.com/)
* **LLM Provider:** [Groq](https://groq.com/) (Model: Llama 3.3 70B Versatile)
* **Data Handling:** Pandas

---

## 🚀 Getting Started

Follow these steps to run the application on your local machine:

### 1. Clone the repository
```bash
git clone [https://github.com/youssef-mm/AI-Financial-Advisor.git](https://github.com/youssef-mm/AI-Financial-Advisor.git)
cd AI-Financial-Advisor bash
```
### 2. Install the required dependencies
Make sure you have Python installed, then run:
``` bash
pip install -r requirements.txt
```
### 3. Get your API Key
Go to the Groq Console and create a free API Key.

### 4. Run the application
```bash
streamlit run app.py
```
### 💡 How to Use
Open the local link provided in your terminal (usually http://localhost:8501).

Enter your Monthly Income and Expenses in the sidebar.

Input your specific financial goal (Optional).

Click Analyze Budget 🚀.

Securely input your Groq API key when prompted in the system to generate the AI report.
